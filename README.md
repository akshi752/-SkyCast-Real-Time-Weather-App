# 🌤️ SkyCast – Weather App

A simple React.js weather application that shows real-time weather data for any city using the OpenWeather REST API.

---

## 🚀 Features
- Search weather by city name  
- Shows temperature, humidity, min/max temp  
- Dynamic UI based on weather (sun, rain, cold)  
- Error handling for invalid cities  

---

## 🛠️ Tech Stack
- React.js  
- OpenWeather REST API  
- Material UI  
- CSS
